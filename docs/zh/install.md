# 在 Mac 上安装应用

安装包已用 Apple 开发者身份签名并经 Apple 公证，双击就能打开。（English:
[Installing the app](../install.md)）

## 1. 下载并拷入

打开[发布页](https://github.com/lydiablllue/firetoad/releases)，下载
`FIRE-Toad-<版本>.dmg`，双击它，把 **FIRE Toad** 拖到旁边的 **Applications（应用程序）**
文件夹上。磁盘映像里还有一份写着这几步的简短说明。

## 2. 第一次打开

在「应用程序」里双击 FIRE Toad。macOS 会问一次：*"FIRE Toad"是从互联网下载的应用。你确定要打开吗？*
点 **打开**。之后每次都是直接双击。不需要联网：Apple 的公证凭证已经附在应用上。

如果对话框说应用*已损坏*，是下载没完成：删掉，重新下载磁盘映像。如果 macOS 说*无法验证*这个应用，
你下载的是 1.0.4 之前没签名的版本：请下载最新版。

## 3. 然后

应用会问你的文件夹在哪。选 **Make one（新建一个）**，指定一个空文件夹（放文档的地方都行，Mac 上
iCloud 云盘也可以）。浏览器打开建账向导：六屏，第一屏就是放上个月对账单的地方——
**[第一次要多久](../../README.zh.md#开始)**。以后每次打开直接进同一个文件夹。

## 签名意味着什么

Apple 检查了安装包里有没有已知的恶意软件，并记下了是谁做的；它没有审查应用做什么。这一点你可以自己查：
整个应用就是这个仓库，`build/build.py` 就是安装包的做法。
