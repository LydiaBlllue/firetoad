# 在 Mac 上安装应用

安装包还没有用 Apple 开发者身份签名，所以第一次打开多一步；之后每次都是双击。（English:
[Installing the app](../install.md)）

## 1. 下载并拷入

打开[发布页](https://github.com/lydiablllue/fire-toad/releases)，下载
`FIRE-Toad-<版本>.dmg`，双击它，把 **FIRE Toad** 拖到旁边的 **Applications（应用程序）**
文件夹上。磁盘映像里还有一份写着这几步的简短说明。

## 2. 第一次打开

**macOS 15（Sequoia）及更新**

1. 在「应用程序」里双击 FIRE Toad。macOS 会说 *"FIRE Toad"未打开——Apple 无法验证"FIRE Toad"是否
   包含恶意软件*。点 **完成**（不要点「移到废纸篓」）。
2. 打开 **系统设置 → 隐私与安全性**，拉到最底下，有一行 *已阻止"FIRE Toad"以保护 Mac*。点
   **仍要打开**，输密码或 Touch ID 确认。
3. 再弹一次对话框，点 **打开**。

**macOS 14（Sonoma）及更早**

1. 在「应用程序」里右键（或按住 Control 点）FIRE Toad，选 **打开**。
2. 这次对话框里有「打开」按钮，点它。

如果对话框说应用*已损坏*，是下载没完成：删掉，重新下载磁盘映像。

## 3. 然后

应用会问你的文件夹在哪。选 **Make one（新建一个）**，指定一个空文件夹（放文档的地方都行，Mac 上
iCloud 云盘也可以）。浏览器打开建账向导：六屏，第一屏就是放上个月对账单的地方——
**[第一次要多久](../../README.zh.md#开始)**。以后每次打开直接进同一个文件夹。

## 为什么多这一步

任何没经过 Apple 公证的应用 macOS 都会这样问，而公证需要付费的开发者账号。路线图的下一版就是
签名版，应用本身不会有别的变化。在那之前，应用只在构建它的那台机器上签了名；它做的每一件事都
可以查：整个应用就是这个仓库，`build/build.py` 就是安装包的做法。
