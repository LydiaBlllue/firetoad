FIRE蛙 FIRE Toad
English

你的钱，一页看完。给在加拿大追求财务自由的人。

每个月把银行对账单放进一个文件夹。FIRE蛙在你的 Mac 上读取它们，核对每份对账单是否对平，给每笔消费归类，再生成一个页面：花了多少、有多少、离财务自由还有几年。

打开在线 demo 下载 Mac 版（免费）

demo 是一位虚构用户的页面，什么都不用装（页面是英文的）。app 经过 Apple 签名和公证，有中文和英文，免费开源（MIT）。

demo 是为电脑屏幕做的；在手机上，可以先看下面的截图。

  • 不登录银行。对账单你自己下载，app 在你的电脑上读，什么都不上传，也不用注册。
  • 每个数都对得上。一份对账单要和它自己印的合计对平，才会收进来。
  • 不只是记账，还有 FIRE 计划。离财务自由几年、钱能撑多久；TFSA、RRSP、FHSA 和国外的钱，都算进一个净值。

能读哪些文件

RBC 和 BMO 的 PDF 对账单；任何银行的 OFX 或 QFX 下载（TD、Scotiabank、CIBC、Tangerine 等都提供）；Wealthsimple 的持仓和交易导出。没有文件的余额，每月填一次就行。每家银行和券商 →
