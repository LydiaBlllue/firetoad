# 在 Mac 上安装应用

安装包已用 Apple 开发者身份签名并经 Apple 公证，双击就能打开。（English:
[Installing the app](../install.md)）

## 1. 下载并打开

打开[发布页](https://github.com/lydiablllue/firetoad/releases)，下载
`FIRE-Toad-<版本>.dmg`，双击它。在弹出的窗口里**双击 FIRE Toad**，不用拖。磁盘映像里还有一份写着这几步的简短说明。

macOS 会问一次：*"FIRE Toad"是从互联网下载的应用。你确定要打开吗？* 点 **打开**。FIRE Toad 会把自己拷进
**应用程序**（不是管理员的账户，拷进你个人文件夹里的「应用程序」），从那里打开，并推出磁盘映像。
要等几秒，浏览器会自己打开。不需要联网：Apple 的公证凭证已经附在应用上。

## 2. 以后

从「应用程序」或启动台打开 FIRE Toad。新版本也这样装，会替换旧的。

如果对话框说应用*已损坏*，是下载没完成：删掉，重新下载磁盘映像。如果 macOS 说*无法验证*这个应用，
你下载的是 1.0.4 之前没签名的版本：请下载最新版。

## 3. 然后

第一次打开，应用会问你的文件夹。点 **新建文件夹**：它会替你建在「文稿」里，名字是 *FIRE Toad*
（这个名字已被别的东西占用时叫 *FIRE Toad 2*），并用通知告诉你在哪。已经有了就点 **打开文件夹**。浏览器打开建账向导：六屏，第一屏就是放上个月对账单的地方——
**[第一次要多久](../../README.zh.md#开始)**。以后每次打开直接进同一个文件夹。

## 签名意味着什么

Apple 检查了安装包里有没有已知的恶意软件，并记下了是谁做的；它没有审查应用做什么。这一点你可以自己查：
整个应用就是这个仓库，`build/build.py` 就是安装包的做法。
